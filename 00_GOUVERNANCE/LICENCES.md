### Ce que la licence Extended permet pour Smart Collab

- Utiliser et modifier le code de DreamsERP dans **un seul produit final**, Smart Collab, y compris quand ses utilisateurs paient (abonnement ou installation chez le client).
- Livrer Smart Collab compilé à nos clients, en ligne ou sur leur serveur.

### Ce qu'elle ne permet pas

- Revendre ou partager le code DreamsERP seul, ou en faire un modèle, un kit d'interface ou un thème vendu à part.
- Utiliser ce même achat pour un **second produit** distinct de Smart Collab (il faudrait une autre licence).
- Publier le code DreamsERP dans un dépôt public : le dépôt `smart-collab` reste **privé**.

Termes de référence : licences ThemeForest Regular / Extended, et rubrique « License » de `https://dreamserp.dreamstechnologies.com/documentation/`. En cas de doute sur un usage, vérifier ces termes avant de livrer.
